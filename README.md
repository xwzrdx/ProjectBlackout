# ProjectBlackout

Server Emulator for Project Blackout (2011 client)

Project Blackout is the OG version, before Point Blank/Piercing Blow rebrand with new devs & publishers!



# Done
* Login (Wrong ID or Password Check)
* Create Nickname + Nickname already exists
* Shop Items
* Player Currencies
* Player Level
* Player Exp
* Player Inventory
* Equip Items
